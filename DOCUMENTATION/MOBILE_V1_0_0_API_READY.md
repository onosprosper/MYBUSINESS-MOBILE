# MYBUSINESS Mobile v1.0.0 API Ready

This release continues the existing Android mobile foundation and connects it to the stable `/api/v1` backend tested on 23 Sep 2026.

## Working backend endpoints used
- `POST /api/v1/auth/login`
- `GET /api/v1/overview`
- `GET /api/v1/products`
- `GET /api/v1/customers`
- `GET /api/v1/orders`
- `GET /api/v1/reports/summary?period=monthly`
- `GET /api/v1/debts`

## App purpose
The Android app is for the business owner, not the customer. Customers continue to use WhatsApp.
